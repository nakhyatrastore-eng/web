# Nakhyatra - Coming Soon Landing Page

A luxury, minimal, fully responsive coming soon landing page built with **Next.js 14** and **Vercel**.

## ✨ Features

- **Luxury Design** - Warm, elegant aesthetic with premium typography
- **Mobile-First** - Perfectly responsive on all devices (mobile to desktop)
- **Zero Scrolling** - Full-height viewport, fits perfectly on screen
- **Typography-Based** - Beautiful Playfair Display serif font instead of images
- **Instagram Integration** - Direct link to [@nakhyatra.store](https://www.instagram.com/nakhyatra.store)
- **Optimized Spacing** - Fluid, proportional spacing using CSS clamp()
- **Fast Loading** - Pure CSS styling, minimal assets
- **Vercel Ready** - Optimized for seamless deployment

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ (installed)
- npm (comes with Node.js)

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open in browser
# http://localhost:3000
```

### Build for Production

```bash
npm run build
npm start
```

## 🎨 Design Highlights

- **Color Palette:**
  - Primary: `#fdfbf8` (warm cream)
  - Text: `#2a2520` (deep brown)
  - Accent: `#d4a76a` (warm gold)

- **Typography:**
  - Brand: Playfair Display (serif)
  - Body: System fonts (-apple-system, etc.)
  - Letter-spacing: `0.22em` for elegance

- **Responsive Breakpoints:**
  - Mobile: `<360px`
  - Tablet: `768px+`
  - Desktop: `1024px+`
